# Лабораторная работа 5 — Построение дашбордов

## Домашнее задание

Нужно изучить учебный ролик и подготовить интеллект-карту по построению дашбордов.

## Лабораторная работа

Тема: «Построение дашбордов». Требуется создать интерактивный дашборд на Dash с данными CSV и как минимум пятью интерактивными элементами: графиками, таблицей, фильтрами и индикаторами.

В будущей реализации дашборд будет показывать показатели процесса обработки заказов: время реакции, своевременность доставки, состояние документов, риски и загрузку перевозчиков.
