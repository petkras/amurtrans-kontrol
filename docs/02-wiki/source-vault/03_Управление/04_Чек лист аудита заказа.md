# Чек лист аудита заказа

Используется руководителем операций для выборочной проверки завершённых заказов. Цель проверки — найти системные ошибки процесса, а не оценить сотрудника по одному случаю.

## Приём и согласование

- [ ] Указаны клиент, договор и плательщик.
- [ ] Полностью описаны груз, маршрут и временные окна.
- [ ] Есть зафиксированное подтверждение стоимости и срока.
- [ ] Версия расчёта соответствует фактически оказанной услуге.

## Исполнение

- [ ] Машина и водитель назначены до подачи.
- [ ] В карточке есть фактические статусы по ключевым точкам.
- [ ] Отклонения зарегистрированы с причиной и решением.
- [ ] Клиент получил уведомление при риске опоздания.

## Закрытие

- [ ] Есть документ о приёмке груза или причина его отсутствия.
- [ ] Счёт соответствует согласованной или документально изменённой стоимости.
- [ ] Претензия, если была, имеет итоговое решение.
- [ ] Заказ не содержит незакрытых задач и неопределённого статуса.

## Итог аудита

Результат классифицируется как: `без замечаний`, `незначительное замечание`, `существенное замечание`, `критическое нарушение`. Для существенных и критических замечаний создаётся корректирующее действие с владельцем и сроком проверки.
