# Глоссарий

| Термин | Определение в рамках процесса |
|---|---|
| Заказ | зарегистрированная заявка клиента на перевозку с номером и набором условий |
| Рейс | фактическое исполнение перевозки; один заказ может содержать несколько рейсов |
| ETA | прогнозное время прибытия на точку маршрута |
| ТТН | транспортная накладная, фиксирующая передачу груза и условия перевозки |
| УПД | универсальный передаточный документ, используемый для подтверждения операции |
| Временное окно | согласованный интервал, в котором транспорт может прибыть на точку |
| Плечо маршрута | участок движения между двумя последовательными точками |
| Подача | прибытие автомобиля на место погрузки или выгрузки |
| Простой | время ожидания, которое превышает согласованный бесплатный период |
| Претензия | формальное требование клиента, связанное с качеством, сроком или сохранностью груза |
| KPI | измеримый показатель качества и эффективности процесса |

## Единые правила терминов

В Wiki используется слово «заказ» для коммерческой единицы работы с клиентом и слово «рейс» для фактического движения автомобиля. Это различие важно при частичной доставке, переносе даты или разделении груза между несколькими автомобилями.
