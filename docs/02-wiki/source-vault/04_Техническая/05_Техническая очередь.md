# Техническая очередь

| Приоритет | Задача | Критерий завершения |
| --- | --- | --- |
| Высокий | История статусов заказа | в карточке видны автор, время и причина каждого изменения |
| Высокий | Контроль обязательных документов | нельзя закрыть заказ без выбранного комплекта документов |
| Средний | Импорт GPS-событий | координаты и время отображаются в рейсе |
| Средний | Шаблоны уведомлений | сообщения формируются из статуса и данных заказа |
| Низкий | Дашборд загрузки перевозчиков | доступны агрегированные показатели по периодам |

Приоритет пересматривается еженедельно владельцем продукта и техническим руководителем. В очередь попадают только задачи с понятным результатом и критерием проверки.
