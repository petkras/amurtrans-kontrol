# Безопасность

## Угрозы и меры

| Риск | Мера защиты |
| --- | --- |
| Доступ к чужому заказу | ролевая модель доступа и проверка прав в API |
| Потеря документов | отдельное файловое хранилище и резервное копирование |
| Подмена статуса перевозки | журнал событий с автором и временем изменения |
| Утечка персональных данных | минимизация полей, защищённое соединение и разграничение прав |
| Ошибочный массовый экспорт | ограничение выгрузок и регистрация действий |

## Правила доступа

Менеджер видит заказы своего подразделения, диспетчер — назначенные рейсы, водитель — только собственные задания, бухгалтер — документы и финансовые статусы. Администратор не редактирует содержание заказов без записи в журнале действий.

Пароли не хранятся в открытом виде. Соединение с системой выполняется по HTTPS. Для внешних интеграций используются отдельные ключи доступа с ограниченным набором операций.
