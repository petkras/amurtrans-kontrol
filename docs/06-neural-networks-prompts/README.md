# Лабораторная работа 6 — Нейронные сети и промпты

## Домашнее задание

Нужно изучить чат-боты и нейронные сети, подготовить определения базовых понятий и классификацию, а также список полезных ресурсов.

## Лабораторная работа

Тема: «Правила написания промптов». В работе потребуется составить пять промптов для разных задач, сравнить результаты с промптами и без них, оценить точность ответов и сделать вывод об эффективности формулировок.
