# Лабораторная работа 1 — Поиск и нейросетевые инструменты

## Лабораторная работа

Тема: «Современные инструменты и методы поиска информации». В работе сопоставлялись результаты обычного веб-поиска и ИИ-поиска, а также проверялось влияние поисковых операторов на выдачу.

Отчёт находится в папке `materials`.
