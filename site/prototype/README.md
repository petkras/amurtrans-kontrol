# Макет рабочих экранов «АмурТранс Контроль»

Откройте `index.html` в браузере и переключайте четыре раздела: заявка, согласование, диспетчер, завершение. Макет статический: кнопки действий показывают размещение управления, но не меняют реальные заказы. Навигационные вкладки работают; каждую вкладку можно открыть по прямой ссылке с фрагментом `#request`, `#quote`, `#dispatch`, `#close`.

Соответствие BPMN: клиент передаёт заявку на первом экране; логистический расчёт и решение клиента показаны на втором; назначение, рейс и исключения — на третьем; подтверждение доставки и проверка документов — на четвёртом. Визуальная система повторяет Wiki: белый фон, зелёно-серая основа и умеренный оранжевый акцент для внимания к отклонениям.

Исходные два SVG-макета карточки заказа и диспетчерского обзора сохранены в родительской папке. Прототип расширяет их, а не заменяет. Все имена, даты и суммы являются демонстрационными.
