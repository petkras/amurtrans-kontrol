# АмурТранс Контроль

Русскоязычная Wiki проектируемого продукта для обработки заказов транспортной компании. Учебный вариант 8 по дисциплине «Современные программные средства».

Сайт описывает предметную область, продукт, сквозной процесс, модель данных, архитектуру, требования, безопасность и тестирование. В архитектуре Telegram-бота описано применение языковой модели как вспомогательного разбора текста. Сам сайт не принимает реальные заказы.

## Просмотр

Собранный статический сайт находится в [`site/index.html`](site/index.html). Для публикации предназначен GitHub Pages.

## Структура

- `docs/` — исходные материалы учебной Wiki и лабораторные артефакты.
- `site_src/` — шаблон, стили, скрипт поиска, SVG-схемы и сборка сайта.
- `site/` — готовый статический сайт.
- `.github/workflows/pages.yml` — сборка и публикация в GitHub Pages после загрузки репозитория.

## Локальная сборка

Нужен Python 3.10 или новее.

```bash
python -m pip install -r requirements-site.txt
python site_src/build.py
python site_src/check_site.py
```

Откройте `site/index.html` в браузере. Поиск работает локально без сервера: индекс встроен в HTML каждой страницы. Его можно вызвать кнопкой или `Ctrl+K`.

## Публикация

Создайте репозиторий GitHub и отправьте файлы в ветку `main`. В настройках репозитория `Settings → Pages → Build and deployment` выберите `GitHub Actions`. Workflow соберёт сайт, проверит локальные ссылки и опубликует его. Токены бота и персональные данные сюда не добавляются.

## Источник и статус данных

Основной контент берётся из `docs/02-wiki/source-vault`. Целевые KPI, учебные кейсы и концептуальные макеты обозначены как проектные материалы, не как статистика действующей компании.
